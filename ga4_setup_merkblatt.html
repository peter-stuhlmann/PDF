Google Analytics 4 – API-Zugang einrichten

Am Ende hast du zwei Dinge: eine JSON-Schlüsseldatei und die Property-ID.

1

Google Analytics Data API aktivieren

Google Cloud Console
  1. console.cloud.google.com öffnen und anmelden.
  2. Oben ein Projekt auswählen oder Projekt erstellen.
  3. Links APIs & Dienste › Bibliothek öffnen.
  4. Google Analytics Data API suchen, anklicken und Aktivieren.
2

Dienstkonto erstellen

Google Cloud Console
  1. APIs & Dienste › Anmeldedaten öffnen.
  2. + Anmeldedaten erstellen › Dienstkonto wählen.
  3. Namen eingeben, z. B. ga4-reporting-bot (ID füllt sich automatisch).
  4. Erstellen und fortfahren, danach Fortfahren und Fertig.
3

JSON-Schlüssel herunterladen

Google Cloud Console
  1. Das neue Dienstkonto anklicken (endet auf …iam.gserviceaccount.com).
  2. Tab Schlüssel öffnen.
  3. Schlüssel hinzufügen › Neuen Schlüssel erstellen.
  4. JSON wählen und Erstellen – die Datei wird heruntergeladen.
4

Dienstkonto in GA4 freigeben

Google Analytics
  1. E-Mail-Adresse des Dienstkontos kopieren (endet auf …iam.gserviceaccount.com).
  2. analytics.google.com öffnen, unten links Verwaltung (Zahnrad).
  3. Prüfen, dass in der mittleren Spalte die richtige Property ausgewählt ist.
  4. Kontozugriffsverwaltung › + › Nutzer hinzufügen.
  5. E-Mail einfügen, Rolle Betrachter wählen und Hinzufügen.
5

Property-ID notieren

Google Analytics
  1. In GA4 unten links Verwaltung öffnen und die richtige Property prüfen.
  2. Property-Einstellungen anklicken.
  3. Die Property-ID oben rechts kopieren – nur Ziffern, z. B. 123456789.
Wichtig: Die JSON-Datei ist ein Zugangsschlüssel. Nicht per E-Mail verschicken, nicht in Git oder öffentliche Ordner legen. Nicht mehr benötigte Schlüssel in der Cloud Console löschen.
